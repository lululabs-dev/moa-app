# 모아(MOA) App Store 사이트

모아 iOS 앱의 소개, 지원, 개인정보 처리방침과 이용약관을 제공하는 정적 GitHub Pages 사이트입니다.

## 경로

- `/`: 앱 소개
- `/support/`: App Store Connect 지원 URL
- `/privacy/`: App Store Connect 개인정보 처리방침 URL
- `/terms/`: 서비스 이용약관

## 로컬 확인

```bash
python3 -m http.server 4177
```

이 사이트는 쿠키, 분석 도구, 로그인, 결제 또는 사용자 데이터 수집 기능을 포함하지 않습니다.
